One out-of-office auto-reply written as if a houseplant sent it, built for the make.fun bounty **"The Houseplant Out-of-Office"**. A judge model ranks the lines pairwise on funniness and originality — this entry's angle is the replacement plant: the one by the window died of neglect in March, the office bought a new one, and the new one has not been watered either.

## Run it

```sh
python3 main.py
```

That writes the reply to `/output/entry.txt` (one line, 105 characters).
